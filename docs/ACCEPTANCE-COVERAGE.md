# Aplyd Genie Acceptance Coverage

All 270 acceptance criteria have corresponding Bug Off cases, organized into 21 epic folders. Each of the 90 BTF stories links to its three cases; each case links back to the story.

See [live traceability](TRACEABILITY.md) for every actual tracker link and [detailed specifications](EPICS-AND-USER-STORIES.md) for the criteria.

All cases are Draft / Not run. Import verification checks persisted content and mappings; it does not execute product tests or establish release acceptance.

Coverage includes authorization and tenant isolation, stale sources, retries and duplicate protection, partial completion, timezone handling, prompt injection, quota exhaustion, provider failures, retention, and recovery.
