## Cross-cutting release scenarios
- A revoked permission blocks a previously approved pending mutation.
- Source document edit requires revalidation of a stale plan.
- Repeated job delivery creates no duplicate tasks or calendar events.
- Worker interruption after mutation reconciles the outcome before retry.
- Tasks succeed while event creation fails; UI reports partial completion.
- Malicious instructions in source content cannot authorize additional tools.
- Cross-tenant retrieval exposes neither content nor inaccessible metadata.
- Exhausted budget rejects new inference without disabling manual apps.
- GPU unavailability leaves jobs bounded and status readable.
- Timezone boundary and daylight-saving cases preserve intended event times.
- Backup restoration demonstrates the approved recovery objective.
